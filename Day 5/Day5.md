Day 5 – Context Engineering
Objective

To understand how Context Engineering improves AI-generated responses by providing additional background information and user-specific details.

Prompt A (Without Context)
Prompt
Create a 30-day learning roadmap.

Include:
- Weekly milestones
- Daily tasks
- Resources
- Projects
- Final outcome

Make it practical and beginner-friendly.
Summary of Output

The AI generated a generic 30-day learning roadmap with weekly goals, daily activities, recommended resources, simple projects, and a final outcome. The plan was useful but broad, without considering any personal preferences, available time, or current skill level.

Screenshot: Add Prompt A output screenshot here

Prompt B (With Context)
Prompt
Create a 30-day learning roadmap.

Context:
- Current Situation: Student
- Current Skills: Basic Python, GitHub, Prompt Engineering fundamentals, Basic Machine Learning concepts
- Goal: Build a strong foundation in AI/ML and create 2 beginner-friendly portfolio projects
- Available Time: 2 hours per day
- Experience Level: Beginner
- Preferred Learning Style: Projects and Videos

Include:
- Weekly milestones
- Daily tasks
- Resources
- Projects
- Final outcome

Make it practical and beginner-friendly.
Summary of Output

The AI generated a personalized AI/ML learning roadmap tailored to my background and goals. The plan focused on Python practice, machine learning fundamentals, project-based learning, and building a portfolio while fitting into my available study time.

Screenshot: Add Prompt B output screenshot here

Comparison of Both Outputs
1. Which roadmap feels more personalized?

The roadmap generated using Prompt B feels much more personalized because it takes into account my current skills, learning goals, available time, and preferred learning style.

2. Which roadmap would you actually follow?

I would follow the roadmap created from Prompt B because it is realistic, practical, and aligned with my goal of building AI/ML skills and portfolio projects.

3. What role did context play in improving the result?

Context helped the AI understand my situation and requirements. By providing details about my background and objectives, the AI created a roadmap that was more relevant, actionable, and easier to follow. This demonstrates that better context leads to better AI-generated outputs.

Key Learnings
Context Engineering helps AI generate more accurate and personalized responses.
Adding user-specific details significantly improves the relevance of the output.
Generic prompts produce broad results, while contextual prompts create practical and targeted solutions.
Providing information such as goals, experience level, and available time enables AI to deliver better recommendations.
Conclusion

This activity demonstrated the importance of Context Engineering in AI prompting. The comparison between the two prompts showed that including relevant context transforms a generic response into a customized and highly useful one.
