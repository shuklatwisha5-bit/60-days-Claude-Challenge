# Day 2 - Prompt Engineering Challenge

## Objective

To understand how prompt engineering improves AI-generated outputs by comparing a simple prompt with a detailed engineered prompt.

## Prompts Used

### Lazy Prompt

Create an image explaining Prompt Engineering.

### Engineered Prompt

Create a professional educational infographic explaining Prompt Engineering for beginners.

Include:

* Definition of Prompt Engineering
* Why Prompt Engineering is important
* Examples of good and bad prompts
* Benefits of effective prompting
* Best practices for writing prompts
* Real-world applications

Use a clean layout, clear headings, icons, and concise explanations suitable for students.

## Activities Performed

1. Opened Claude and created a new chat.
2. Generated an image using the lazy prompt.
3. Saved the generated output.
4. Opened a new chat in Claude.
5. Generated an image using the engineered prompt.
6. Compared both outputs based on content quality and design.
7. Documented observations and learnings.
8. Uploaded the work to GitHub.

## Comparison

| Aspect         | Lazy Prompt       | Engineered Prompt          |
| -------------- | ----------------- | -------------------------- |
| Clarity        | Basic explanation | Detailed explanation       |
| Structure      | Less organized    | Well-structured sections   |
| Examples       | Few or none       | Multiple relevant examples |
| Design         | Simple layout     | Professional infographic   |
| Learning Value | Moderate          | High                       |

## Key Learnings

* Detailed prompts produce better AI responses.
* Providing context and instructions improves output quality.
* Prompt engineering helps AI generate more accurate and useful content.
* Structured prompts lead to better organization and presentation.

## Conclusion

This activity demonstrated the importance of prompt engineering. A well-crafted prompt provides clearer instructions to the AI, resulting in more informative, organized, and visually appealing outputs compared to a simple prompt.
